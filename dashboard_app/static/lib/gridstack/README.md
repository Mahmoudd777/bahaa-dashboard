# Gridstack.js (vendored)

- Source: https://github.com/gridstack/gridstack.js (v12, via jsDelivr)
- License: **MIT** (compatible with this module's LGPL-3) — see `gridstack-all.js.LICENSE.txt` header.
- Files: `gridstack-all.js` (UMD, sets `window.GridStack`), `gridstack.min.css`.

Powers the dashboard **edit mode** drag/resize grid (`gridstack_editor.js`). View mode
does not use it. Bundled locally (not CDN) so the module works offline, same pattern
as the vendored gsap / flatpickr libs.
