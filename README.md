# Bahaa Dashboard

Odoo 19 custom addons for the **Bahaa Dashboard** — a white-labelled, dynamic, themeable strategic office dashboard.

## Contents

| Module | Description |
|--------|-------------|
| `dashboard_app` | Al-Baha Strategic Office dashboard (GridStack layout, themes, login branding, import tools) |

## Requirements

- Odoo **19.0**
- Python 3.11+
- Dependencies: `base`, `web`

## Install

1. Add this repository to your Odoo `addons_path` (or copy `dashboard_app` into your custom addons folder).
2. Update the Apps list.
3. Install **Dashboard App**.

```text
addons_path = ...,/path/to/bahaa-dashboard
```
